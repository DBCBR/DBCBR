### 📂 Projetos em Destaque

#### 🚀 [Task Manager API](https://github.com/DBCBR/task-manager-api)
* **O que é:** Uma API RESTful robusta para gerenciamento de tarefas com foco em segurança, produtividade e qualidade.
* **Tecnologias:** FastAPI, PostgreSQL, SQLAlchemy, Docker, Pytest, OAuth2 (JWT).
* **Diferenciais:** Isolamento completo de dados entre usuários, validação inteligente de prazos (`due_date`) com tolerância de 15 minutos, painel de estatísticas agregado direto via banco e suíte de testes integrada sem warnings.

#### 🔗 Integration Platform (SimpliRoute + Oracle)
* **O que é:** Plataforma de integração contínua conectando tabelas de sistemas legados de banco de dados à API de roteamento SimpliRoute.
* **Tecnologias:** Python, FastAPI, Docker, PostgreSQL.
* **Diferenciais:** Normalização transacional de dados e workflows automatizados.

#### 📊 AutoFin - Automated Expense Tracker
* **O que é:** Aplicação de microsserviços para captura e classificação automática de transações financeiras.
* **Tecnologias:** FastAPI, Celery, PostgreSQL, Docker.
